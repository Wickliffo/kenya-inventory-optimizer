# Real WFP Kenya price-data profile

This profile was generated from `data/public/wfp_food_prices_ken.csv`. It is a market-price dataset, not an employer demand dataset.

- Rows after basic date/price cleaning: **29,298**
- Date range: **2006-01-15 to 2026-10-15**
- Markets: **227**
- Commodity labels: **51**

## Price types

- Retail: 19,897
- Wholesale: 9,401

## Interpretation

The file is appropriate for Kenyan price context, volatility analysis and ARIMAX experiments. It cannot measure company sell-through, stockouts, inventory position or supplier capacity. Those inputs must come from an employer operations export.
